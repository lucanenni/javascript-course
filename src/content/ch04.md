## La logica condizionale

«Se piove prendo l'ombrello, altrimenti esco in maglietta.» Un programma deve poter scegliere strade diverse in base ai dati. Lo strumento è l'istruzione `if`.

## La sintassi di if / else

Scrivi `if`, poi una **condizione** tra parentesi tonde, poi un blocco di codice tra parentesi graffe `{ }`. Il blocco viene eseguito **solo se** la condizione è `true`. Con `else` indichi cosa fare altrimenti, e con `else if` aggiungi altri casi.

```diff-demo Da if semplice a catena if / else if / else
let ora = 14;

if (ora < 12) {
  console.log("Buongiorno");
}
@@@
let voto = 7;

if (voto >= 8) {
  console.log("Ottimo");
} else if (voto >= 6) {
  console.log("Sufficiente");
} else {
  console.log("Insufficiente");
}
```

::: tip La condizione è un booleano
Tra le parentesi di `if` ci va qualcosa che vale `true` o `false`: un confronto (`eta >= 18`), una variabile booleana, o una combinazione con `&&` / `||`.
:::

## Esercizio

In base al valore di `voto`, assegna alla variabile `giudizio` la stringa giusta: `"ottimo"` (8–10), `"sufficiente"` (6–7) oppure `"insufficiente"` (sotto il 6). Prova poi a cambiare `voto` e verifica che l'output segua.
