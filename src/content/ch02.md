## Cosa sono le variabili

Una variabile è una **scatola con un'etichetta**: l'etichetta è il nome, dentro c'è un valore che puoi leggere o cambiare più avanti nel programma. Invece di ripetere `"Mario Rossi"` ovunque, lo metti una volta in `nomeUtente` e poi usi quel nome.

## let e const

Per creare una variabile usi `let` o `const`, seguìto dal nome, dal segno `=` e dal valore iniziale.

- `const` — per valori che **non cambieranno mai** (una costante). Se provi a riassegnarli, ottieni un errore.
- `let` — per valori che **cambieranno** nel tempo (un punteggio, un contatore).
- Regola pratica: usa sempre `const`, e passa a `let` solo quando ti accorgi che devi riassegnare la variabile.

```diff-demo const non si riassegna, let sì
const nome = "Mario";
nome = "Luigi";   // ERRORE: Assignment to constant variable
@@@
let punteggio = 0;
punteggio = 10;   // ok
punteggio = 15;   // ok
```

## I tipi di dato principali

Ogni valore ha un **tipo**. All'inizio ti bastano tre tipi:

- **string** — testo tra virgolette: `"ciao"`, `'42 gatti'`
- **number** — numeri interi o decimali: `42`, `3.14`, `-7`
- **boolean** — solo due valori, `true` o `false` (vero / falso)

Puoi chiedere il tipo di un valore con `typeof`: `typeof "ciao"` restituisce `"string"`. Esistono anche `undefined` (una variabile dichiarata senza valore) e `null` (un «vuoto» messo di proposito).

::: warning Attenzione al + con le stringhe
Con i numeri `+` somma: `5 + 3` fa `8`. Con le stringhe `+` _concatena_: `"5" + "3"` fa `"53"`. E `"Età: " + 30` fa `"Età: 30"` perché il numero viene trasformato in testo.
:::
