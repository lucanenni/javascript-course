## Cos'è una funzione

Una funzione è un blocco di codice con un nome, che puoi **richiamare** tutte le volte che vuoi. Come un frullatore: metti dentro gli ingredienti (gli _argomenti_), lui fa il suo lavoro e ti restituisce un risultato.

La definisci con `function`, un nome, delle parentesi tonde e un blocco `{ }`. La **chiami** scrivendo il suo nome seguìto da parentesi.

## Parametri e return

Tra le parentesi della definizione metti i **parametri**: nomi per i valori che riceverà. Con `return` la funzione **restituisce** un valore a chi l'ha chiamata; dopo `return` la funzione termina.

```diff-demo Funzione che stampa vs funzione che restituisce
function saluta(nome) {
  console.log("Ciao " + nome);
}

saluta("Marco");   // stampa, ma non "vale" niente
@@@
function somma(a, b) {
  return a + b;
}

const totale = somma(5, 10);
console.log(totale);   // 15
```

## Arrow function

C'è una scrittura più breve, le _arrow function_, molto comune nel codice moderno:

```diff-demo Stessa funzione, due sintassi
function doppio(n) {
  return n * 2;
}
@@@
const doppio = (n) => {
  return n * 2;
};

// versione ultra-corta (return implicito):
const doppioCorto = n => n * 2;
```

::: info Le variabili dentro restano dentro
Una variabile dichiarata con `let`/`const` dentro una funzione esiste solo lì (si dice che ha _scope_ locale). Da fuori non la vedi. Questo è un bene: ogni funzione è una scatola chiusa che non sporca il resto del programma.
:::
