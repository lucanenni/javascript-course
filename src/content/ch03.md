## Operatori aritmetici

Con i numeri usi `+` (somma), `-` (sottrazione), `*` (moltiplicazione), `/` (divisione) e `%` (_modulo_: il resto della divisione, utile per capire se un numero è pari).

Un'**espressione** è qualsiasi pezzo di codice che produce un valore: `3 * (2 + 1)` è un'espressione che vale `9`. Le parentesi decidono l'ordine, come in matematica.

## Operatori di confronto

Servono a confrontare due valori e producono sempre un **boolean**:

- `===` uguale a  ·  `!==` diverso da
- `>` maggiore  ·  `<` minore  ·  `>=` maggiore o uguale  ·  `<=` minore o uguale

::: warning Tre uguali, non uno
`=` significa «assegna» (metti un valore nella variabile). `===` significa «è uguale a?». Confondere i due è l'errore numero uno dei principianti. Esiste anche `==`, ma usa sempre `===`: è più prevedibile.
:::

## Operatori logici

Combinano più condizioni booleane:

- `&&` (AND) — vero solo se **entrambe** le condizioni sono vere
- `||` (OR) — vero se **almeno una** è vera
- `!` (NOT) — inverte: `!true` è `false`

```diff-demo Espressioni che producono un booleano
let eta = 20;
eta >= 18            // true
eta === 18           // false
eta % 2 === 0        // true  (20 è pari)
@@@
let eta = 20;
let haBiglietto = true;
eta >= 18 && haBiglietto   // true
eta < 18 || haBiglietto    // true
!haBiglietto               // false
```
