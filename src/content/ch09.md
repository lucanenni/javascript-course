## Cos'è il DOM

Fin qui abbiamo solo stampato nella console. Ma il vero motivo per cui JavaScript esiste è **cambiare la pagina web**. Il browser trasforma l'HTML in una struttura di oggetti chiamata **DOM** (Document Object Model), e JavaScript può leggerla e modificarla.

Il punto d'ingresso è `document`. In questo playground la «pagina» è il riquadro in alto a destra: contiene un titolo, un pulsante e un paragrafo vuoto.

## Selezionare e modificare elementi

- `document.getElementById("titolo")` — prende l'elemento con quell'`id`
- `document.querySelector(".classe")` — prende il primo elemento che corrisponde a un selettore CSS
- `elemento.textContent = "nuovo testo"` — cambia il testo
- `elemento.style.color = "red"` — cambia uno stile

::: warning textContent, non innerHTML
Per inserire testo usa `textContent`. `innerHTML` interpreta il contenuto come HTML: se ci finisce dentro testo scritto da un utente, è una porta aperta per attacchi. Da principiante, attieniti a `textContent`.
:::

## Reagire ai clic

Con `elemento.addEventListener("click", funzione)` dici al browser: «quando qualcuno clicca questo elemento, esegui questa funzione». È così che una pagina diventa interattiva.

```diff-demo Cambiare testo e gestire un clic
const titolo = document.getElementById("titolo");
titolo.textContent = "Testo cambiato da JS";
@@@
const btn = document.getElementById("btn");

btn.addEventListener("click", () => {
  document.getElementById("out").textContent = "Hai cliccato!";
});
```

## Esercizio

Modifica la pagina qui sopra: cambia il titolo e fai reagire il pulsante. Dopo aver scritto il codice, prova a cliccare davvero il pulsante nel riquadro.
