## Cos'è un oggetto

Un array mette in fila valori dello stesso genere. Un **oggetto** invece raggruppa informazioni _diverse_ che descrivono una stessa cosa, ognuna con un nome (la _proprietà_ o _chiave_).

Si scrive tra parentesi graffe `{ }`, con coppie `chiave: valore` separate da virgole:

```diff-demo Creare e leggere un oggetto
const persona = {
  nome: "Ada",
  eta: 36,
  attiva: true
};

console.log(persona.nome);   // "Ada"
console.log(persona.eta);    // 36
@@@
const persona = { nome: "Ada", eta: 36 };

// modificare una proprietà
persona.eta = 37;

// aggiungerne una nuova
persona.citta = "Londra";

console.log(persona);
```

## Notazione con il punto

Per leggere o scrivere una proprietà usi `oggetto.chiave`. Gli oggetti possono contenere array, altri oggetti, o stare dentro un array — è così che si rappresentano i dati veri: `utenti` è un array di oggetti, ognuno con `nome` e `email`.

::: tip Array + oggetti = quasi tutto
La maggior parte dei dati che incontrerai (risposte di un server, righe di un database) sono array di oggetti. Saperli scorrere con un ciclo e leggere le proprietà è una delle abilità più usate.
:::
