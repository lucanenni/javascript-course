## Cos'è un array

Un **array** è una lista ordinata di valori, racchiusa tra parentesi quadre `[ ]` con gli elementi separati da virgole. Serve quando hai «tante cose dello stesso tipo»: una lista della spesa, i voti di un esame, i nomi degli iscritti.

Ogni elemento ha una **posizione** (l'_indice_) che parte da `0`, non da 1. `spesa[0]` è il primo elemento, `spesa[1]` il secondo.

```diff-demo Leggere e contare gli elementi
const spesa = ["pane", "latte", "uova"];

console.log(spesa[0]);       // "pane"
console.log(spesa[2]);       // "uova"
console.log(spesa.length);   // 3  (quanti elementi)
@@@
const spesa = ["pane", "latte", "uova"];
const ultimo = spesa[spesa.length - 1];

console.log(ultimo);         // "uova"
```

## Aggiungere e togliere

- `spesa.push("mele")` — aggiunge in fondo
- `spesa.pop()` — rimuove l'ultimo e lo restituisce
- `spesa.includes("latte")` — `true` se l'elemento c'è
- `spesa.indexOf("uova")` — la posizione di un elemento (o `-1`)

::: info const e array
Puoi modificare il contenuto di un array anche se è dichiarato con `const`: `push` e `pop` funzionano. Quello che `const` vieta è riassegnare l'intera variabile a un altro array.
:::
